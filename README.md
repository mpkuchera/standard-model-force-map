# Standard Model Force Map

An interactive chart of the Standard Model for students. Click a force carrier (g, γ, W, Z, H) to highlight every particle that feels that force, or switch to the **Layers (3D)** view, where each force is a layer and each particle becomes a tower of the forces it feels.

The whole site is one file, `index.html`, with no build step. Fonts load from Google Fonts.

## View locally

Open `index.html` in any browser.

## Host it

Any static host works: GitHub Pages, Netlify, a course web server, or an LMS that accepts HTML files. Upload `index.html` as-is.

Deep link straight to the 3D view with `index.html#layers`.

## Sources

Masses from the Particle Data Group 2024 review. Layout follows the [Standard Model chart on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Standard_Model_of_Elementary_Particles.svg).
